# Fetal Health Classification

Classifies fetal health using Cardiotocography (CTG) data into normal, suspect, or abnormal categories. Includes YOLO-based ultrasound brain-image analysis for segmentation.

## Tech Stack
- **Languages:** Python, JavaScript
- **Frameworks/Libraries:** Flask, OpenCV, YOLO
- **Databases:** SQLite
- **Frontend:** HTML, CSS, JavaScript
